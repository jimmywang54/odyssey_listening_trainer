Odyssey Listening Trainer — PWA

This folder is ready to host as a Progressive Web App.

Fastest deployment options:
1. Netlify Drop: upload this entire folder/ZIP to Netlify's drag-and-drop deploy page.
2. GitHub Pages: upload the folder contents to a repository and enable Pages.
3. Any HTTPS static hosting service.

iPhone installation after hosting:
- Open the hosted URL in Safari.
- Tap Share.
- Tap Add to Home Screen.
- Launch from the new home-screen icon.

Notes:
- PWA installation requires HTTPS (except localhost).
- Core files are cached for offline use after the first successful load.
- Listening uses the device/browser speech synthesis voice, so voice quality depends on iOS/Safari.
- Progress is stored locally on the device/browser.
